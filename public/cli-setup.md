# BitterPass CLI Setup

The BitterPass CLI setup path is invitation-gated. Public marketing explains
what to expect, while detailed commands, pairing steps, runner enrollment, and
recovery material travel only with an approved invitation.

## Setup Path

1. Request access.
2. Complete operator review and pairing approval.
3. Pair the console with a passkey.
4. Enroll a runner identity.
5. Let each run receive one scoped bundle.

Each runner identity uses its own keypair. The operator approves the pairing,
and the runner receives only the material that the approved run should see.

## What The Invitation Carries

Approved invitations carry the current console URL, CLI release notes, pairing
steps, runner-enrollment walkthrough, and the proof path for which material
stays operator-held before a production pilot.

## Public Boundary

This Markdown page is a public overview, not a setup runbook. Do not publish
pairing tokens, recovery material, customer-specific commands, credential
values, or support/debug payloads here.
